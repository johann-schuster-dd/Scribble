# Scribble Support

Come here for everything you need for a smooth project management in Scribble.

## User Interface

Scribble's UI does not use tabs. Instead, it relies on a stacked layout.

This means, the startpage only contains your projects. Tap one of them to go into its detail view. All the work inside a project happens there.

## Projects

Projects are the main organizational layer in Scribble. They are used to store notes, goals and they can be structured into more subtopics using branches.

### Add a Project

You can add a project using the following steps.

1. Make sure you are at the top level, the startpage.
2. Select "New Project" in the top overview card.
3. Firstly, come up with a name for your project. Then, optionally, you can add a subtitile and a deadline when your project needs to be done. Tap "Continue".
4. Now, choose a color and a symbol. Confirm with "Create".

Your new project should now be visible in the list of projects under the overview card.

### Edit or delete project information

Making changes to an existing project is possible like this:

1. On the startpage, select the project.
2. In the top, press the appearing overview card.
3. Now, you see some details about the project. To edit, tap the pencil button to the right in the overview card at the top. To see what you can do in the appearing view, see *Add a device*.
4. Deleting this project is done by scrolling to the bottom. There, tap "Delete Project".

Note that once deleted, **neither your project nor any of its child information will be restorable**.

## Notes, Goals and Branches

### Adding a note or a goal

There are two ways how to add notes and goals to a project.

On the startpage, this is done by pressing "Add note" or "Add goal" on the desired project card. It is also possible by selcecting the project. Scroll down to the notes or goals section, there, add a note or goal, respectively.

### Understanding and managing branches

In a project's detail view, you can already store notes and goals. But often, projects consist of several parts, considered branches. Enter the branch editor by selecting "Branches" in the detail view of a project.

#### Add a branch

From here, you see the button "New Branch". Tap it to create one.

The creation process is similar to this of a project, as you can use titles, subtitles, deadlines and choose a symbol. New for branches is their location. **Tap "Project root" and select the project or branch** inside this project where the new branch should be embedded in. The container where you create the new branch is selected by default.

#### Working in a branch

To work in a branch, first select one from the list. The opening view ressembles this of a project. Add notes and goals here using the same logic as on top-level. Except that here, editing and deleting the branch is done by scrolling to the bottom of the view.

Also, you can add new branches nested inside the branch to the bottom.
